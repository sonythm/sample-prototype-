# sample-prototype-

**Agent orchestration behind a trust perimeter** - an interactive prototype of one layered design (trust perimeter, orchestrator, domain agents, governance, secure integration) applied across seven use cases.

Live: https://sonythm.github.io/sample-prototype-/

## How to run

Open `index.html` in any modern browser (or visit the live page). Press **Run the simulation**, or open a use case (for example `#hospital`, `#prompt-injection`) and use Run workflow / Step through, approve or reject the human checkpoints, then Verify chain or Tamper with entry 2 on the audit ledger.

It is a single self-contained file: vanilla HTML, CSS and JavaScript, light and dark themes, reduced-motion support.

All data is simulated. No third-party requests are made (no CDN, no web fonts, no analytics).
